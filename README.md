# Dispersion tests in generalised linear mixed-effects models: a methods comparison and practical guide for ecologists

Data and code for the simulations and analyses of the study "Dispersion tests in generalised linear mixed-effects models: a methods comparison and practical guide for ecologists".

Case studies data and analysis are in "case_studies" folder.

Simulations were done sequentially with the scripts in "code_simulations". 

Simulations results were stored in "data".

Results and figures were generated using the scripts in "code_results", and the figures were saved in "figures". 

In "functions_others" there are auxiliary functions used during simulations or results and example figures presented in the study manuscript.

Literature review code and list of reviewed papers for Box 2 and supplementary material S1 are in "literature_review".

**An example HTML file of the different dispersion tests available using the DHARMa packag is shown in "docs/index.html"**.
